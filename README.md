
# DAXON - Login and Registration App

DAXON is a simple Flutter application featuring a user login and registration interface.

## Features
- Login page
- User registration page
- Email and password fields
- Full name field
- Custom DAXON logo
- Switch between login and registration

## Technologies Used
- Flutter
- Dart
- Visual Studio Code
